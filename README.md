# Bible Lookup for LyricDisplay

Локальный Windows-инструмент для поиска по Синодальному переводу, подготовки плана показа и вывода текста в LyricDisplay.

## Состав

- `app/` — Electron-приложение для Windows x64.
- `website/` — статический промо-сайт Bible Lookup.
- `app/README_RU.md` — инструкция по запуску и подключению.
- `website/ideas.md` — выбранная визуальная концепция сайта.

## Важно о переводах

Встроен Синодальный перевод со статусом Public Domain по данным eBible. Современный русский перевод в релиз не включён: для его распространения требуется отдельное разрешение правообладателя.

## Лицензия проекта

Исходный код приложения и сайта распространяется по MIT. Тексты Библии имеют отдельные сведения об источнике и правах, указанные в `app/ATTRIBUTION.txt` и интерфейсе приложения.
