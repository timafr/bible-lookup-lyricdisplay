# LyricDisplay Song Controller

Отдельная Windows-программа для автоматического переключения песен в LyricDisplay. Контроллер не хранит собственную копию песни: он получает текущий список строк из LyricDisplay после подключения и работает именно с ним.

## Как пользоваться

Сначала откройте LyricDisplay и добавьте или выберите песню обычным способом. Затем запустите `LyricDisplay Song Controller.exe`, откройте «Подключение», укажите локальный адрес LyricDisplay и 6-значный код из `Tools → Connect Mobile Controller`.

После подключения нажмите «Обновить из LyricDisplay». В окне появятся те же строки, которые сейчас загружены в LyricDisplay. Кнопка «Показать» отправляет выбранный индекс через событие `lineUpdate`, поэтому активная строка меняется непосредственно в LyricDisplay и на его Output/Stage.

В режиме «Авто» контроллер слушает русскую речь, сравнивает распознанные слова с текстом загруженных строк и переключает строку только после достижения порога уверенности. Повторный вывод той же строки блокируется на несколько секунд. В режиме «Предлагать» строка только подсвечивается, а оператор нажимает «Показать» вручную. Кнопка «Пауза слушателя» останавливает микрофон.

## Ограничения первой версии

Для распознавания используется SpeechRecognition, доступный в Electron/Windows. Поведение и качество зависят от установленного речевого движка и микрофона. Лучше всего работают короткие фрагменты с несколькими подряд идущими словами из строки. Аудио не записывается и не сохраняется.

Перед живым служением проверьте подключение, выберите песню в LyricDisplay и протестируйте 2–3 строки вручную. Если авто-переход ошибается, увеличьте порог или включите режим «Предлагать».

## Протокол LyricDisplay

Контроллер использует локальную Socket.IO-сессию с JWT-кодом, запрашивает `currentState`, наблюдает за `serverLyricsLoad` и отправляет `lineUpdate { index }`. Исходная спецификация протокола сохранена в основном репозитории Bible Lookup.


## Версия 1.5.0 — выбор микрофона и ASIO

В панели слушателя можно выбрать конкретный микрофон Windows. После выдачи разрешения список аудиовходов обновляется, выбранное устройство сохраняется и используется при следующем запуске. Контроллер слушает только пока включён слушатель; аудио не записывается и не сохраняется.

Добавлен выбор `Windows audio` / `ASIO bridge`. Программа проверяет наличие нативного ASIO-моста через безопасный IPC-вызов. При отсутствии моста она явно сообщает о fallback и использует выбранный микрофон через Windows audio. Для реального ASIO-захвата потребуется совместимый нативный bridge под конкретный ASIO-драйвер.
